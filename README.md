# श्री रामलीला समिति नेदुला ट्रस्ट

A static, responsive Hindi website based on the live Nedula Ramleela site's shared navigation and page layouts, with the supplied Patti Samiti content.

Open `index.html` directly or serve this folder with any static file server. Pages are available at `/live/`, `/schedule/`, `/gallery/`, `/contact/`, and `/about/` (with Organizers, Members, History, and Guardians subsections). The supplied 2025 invitation / Patti Mela report, its gallery previews, and the Ram Darbar image are local assets. Event dates, committee details, and social links come from the files in Downloads. Run `python3 generate_pages.py` after editing the page definitions to regenerate the static subpages.
